# Phrasal Verbs B2–C1 — PWA v3

## Cambios de esta versión
- 524 entradas.
- Cada entrada abre una ficha al tocar el phrasal verb.
- Cada ficha contiene exactamente 3 ejemplos diferentes.
- En los separables, los ejemplos están escritos con el objeto entre verbo y partícula para demostrar la separación.
- En los inseparables, verbo y partícula/preposición permanecen juntos.
- Los usos intransitivos se tratan como no separables y se explica que no tienen objeto directo que separar.
- La etiqueta **Inseparable** aparece en rojo.
- Audio con `speechSynthesis` del dispositivo.
- Marcado de “Ya lo leí” persistente con `localStorage`.
- Quiz de 4 opciones, por sección o global, con orden aleatorio y barra de progreso.
- Compatible con GitHub Pages y con instalación desde Safari: Compartir → Añadir a pantalla de inicio.

## Nota gramatical
La separabilidad depende del verbo y del sentido. Además, en los phrasal verbs separables, los pronombres normalmente deben colocarse entre el verbo y la partícula: `look it up`, no `look up it`. British Council explica la distinción entre transitivos separables, transitivos no separables e intransitivos.

## Publicar
1. Crea un repositorio en GitHub.
2. Sube todo el contenido de esta carpeta.
3. Activa GitHub Pages usando la rama principal y la carpeta raíz.
4. Abre la URL en Safari en el iPhone.
5. Compartir → Añadir a pantalla de inicio.
